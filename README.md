# EduNest

Jefferson County Home & School Locator is a lightweight client-side web app (HTML/CSS/vanilla JS) for searching local homes and schools using static JSON + GeoJSON data.

## Run locally

Because this app fetches local JSON files, serve it with a static server from the repository root.

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`
